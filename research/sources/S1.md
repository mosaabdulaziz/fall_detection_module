## Problem Addressed
- `[SOURCE: Section 1, Introduction]` Prior skeleton action recognition methods relied on hand-crafted features or RNN/2D-CNN traversal rules that lose the natural kinematic graph topology of human joints. ST-GCN formulates dynamic skeletons as a spatio-temporal graph $G = (V, E)$ with spatial intra-body bone edges $E_S$ and temporal inter-frame joint edges $E_F$.

## Method as Described by the Authors
- **Spatial Graph Convolution (`Section 3.2, Eq. 1–2`):**
  $$f_{\text{out}}(v_{ti}) = \sum_{v_{tj} \in B(v_{ti})} \frac{1}{Z_{ti}(v_{tj})} f_{\text{in}}(v_{tj}) \cdot \mathbf{w}(l_{ti}(v_{tj}))$$
- **Three Partition Strategies (`Section 3.2`):**
  1. *Uni-labeling* ($K=1$): All 1-hop neighbors share one weight vector.
  2. *Distance partitioning* ($K=2$): Root node ($d=0$) and 1-hop neighbors ($d=1$).
  3. *Spatial configuration partitioning* ($K=3$): Partitions 1-hop neighborhood based on distance $r_i$ to the skeleton gravity center (average coordinate of all joints in a frame):
     - Subset 1 (root node): $r_j = r_i$
     - Subset 2 (centripetal / closer to gravity center): $r_j < r_i$
     - Subset 3 (centrifugal / further from gravity center): $r_j > r_i$
- **Matrix Implementation with Learnable Edge Importance (`Section 3.3, Eq. 3`):**
  $$\mathbf{f}_{\text{out}} = \sum_{j} \mathbf{\Lambda}_j^{-\frac{1}{2}} (\mathbf{A}_j \otimes \mathbf{M}_j) \mathbf{\Lambda}_j^{-\frac{1}{2}} \mathbf{f}_{\text{in}} \mathbf{W}_j$$
- **Network Architecture (`Section 3.3 & Section 4.2`):**
  - Input batch normalization followed by **9 ST-GCN layers** (in paper text) with temporal kernel size $\Gamma = 9$: layers 1–3 have 64 channels, layers 4–6 have 128 channels, layers 7–9 have 256 channels; stride 2 temporal downsampling at layers 4 and 7; dropout 0.5 after each ST-GCN unit; global average pooling over $(T, V)$ and SoftMax classifier.

## Exact Reported Results (with Table Locators)
- **`[SOURCE: Table 1, Section 4.2]` Ablation Study on Kinetics-Skeleton:**
  - Baseline TCN: **20.3%** Top-1, **40.0%** Top-5
  - Local Convolution: **22.0%** Top-1, **43.2%** Top-5
  - Uni-labeling: **19.3%** Top-1, **37.4%** Top-5
  - Distance Partitioning* (without weight sharing): **23.9%** Top-1, **44.9%** Top-5
  - Distance Partitioning: **29.1%** Top-1, **51.3%** Top-5
  - Spatial Configuration: **29.9%** Top-1, **52.2%** Top-5
  - **ST-GCN + Imp.** (Spatial Configuration + Edge Importance): **30.7%** Top-1, **52.8%** Top-5
- **`[SOURCE: Table 2, Section 4.3]` Kinetics-Skeleton SOTA Comparison:**
  - Deep LSTM: **16.4%** Top-1, **35.3%** Top-5
  - Temporal ConvNet (TCN): **20.3%** Top-1, **40.0%** Top-5
  - **ST-GCN (Ours):** **30.7%** Top-1, **52.8%** Top-5
- **`[SOURCE: Table 3, Section 4.3]` NTU-RGB+D 60 SOTA Comparison (Top-1 %):**
  - Deep LSTM: 60.7% (X-Sub), 67.3% (X-View)
  - PA-LSTM: 62.9% (X-Sub), 70.3% (X-View)
  - ST-LSTM + TS: 69.2% (X-Sub), 77.7% (X-View)
  - VA-LSTM: 79.4% (X-Sub), 87.6% (X-View)
  - C-CNN + MTLN: 79.6% (X-Sub), 84.8% (X-View)
  - **ST-GCN (Ours):** **81.5%** (X-Sub), **88.3%** (X-View)
