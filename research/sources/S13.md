## Problem Addressed
Real-time multi-person fall detection on CPU or GPU across video files, RTSP streams, and USB webcams using 2D human pose estimation `[SOURCE: GitHub README]`.

## Code Architecture & Implementation Details
1. **Drop-In Package Replacement**:
   - The repository is structured not as an independent Python package, but as modified source files that **overwrite the installed `openpifpaf==0.11.9` site-packages directory** (`openpifpaf/video.py`, `annotation.py`, `stream.py`, `show.py`, etc.) plus `config/config.xml` for configuring video/RTSP paths `[SOURCE: GitHub README]`.
   - Entry point: `python3 -m openpifpaf.video --show` (or `--source {CAMERA_ID} --show`) `[SOURCE: GitHub README]`.
2. **Multi-Person Tracking + Heuristic State Machine (No LSTM/Classifier)**:
   - Integrates a multi-person tracker on top of OpenPifPaf 2D keypoints (correlating neck/centroid coordinates and bounding boxes across sequential frames to maintain person IDs) `[SOURCE: GitHub README / repo summary]`.
   - Uses **geometric bounding-box aspect ratio and keypoint vertical descent heuristics** rather than a neural classifier (no LSTM or MLP) to transition a tracked person ID into a `FALL` state `[SOURCE: GitHub repo summary]`.

## Reported Benchmark Results (from README)
- **Dataset**: UR Fall Detection Dataset (URFD), tested on two NVIDIA Quadro GV100 GPUs `[SOURCE: GitHub README]`.
- **Metrics**:
  - **Precision**: **100%** `[SOURCE: GitHub README]`
  - **Recall**: **83.33%** `[SOURCE: GitHub README]`
  - **F1 Score**: **90.91%** `[SOURCE: GitHub README]`
- **Explicit Limitation Stated by Author in README**:
  - *"Due to dataset limitations, false positives and true negatives were not comprehensively tested"* `[SOURCE: GitHub README]`.
  - This means the 100% precision was only evaluated on positive fall clips without full negative ADL sequence testing, making its false-positive resistance unverified.
