## Problem Addressed & Pipeline Overview
- `[SOURCE: README.md, lines 1-5]` Multi-person human fall detection and action recognition in video streams by chaining:
  1. **Person Detection:** One-class Tiny-YOLO trained on rotation-augmented COCO person dataset (`DetectorLoader.py`).
  2. **2D Pose Estimation:** AlphaPose / SPPE FastPose (`resnet50` or `resnet101`, input `320x256`) extracting 13 COCO keypoints per detected person (`PoseEstimateLoader.py`).
  3. **Multi-Object Tracking:** SORT / DeepSORT Kalman tracker (`Track/Tracker.py`) maintaining a per-track rolling buffer `self.keypoints_list = deque(maxlen=30)` of 30 frames (appended only on matched frames).
  4. **Temporal Skeleton Action Recognition:** Two-Stream Spatial Temporal Graph Convolutional Network (`TSSTG` in `ActionsEstLoader.py`, `TwoStreamSpatialTemporalGraph` in `Actionsrecognition/Models.py`) classifying every 30-frame window into 7 action classes.

## Exact Keypoint Topology (13 Extracted -> 14 Graph Nodes in `coco_cut`)
1. **Stage 1 — Cutting Eyes and Ears from 17 COCO Keypoints (`17 -> 13`):**
   - `[SOURCE: PoseEstimateLoader.py, SPPE_FastPose.predict]`
     ```python
     # Cut eyes and ears (Coco format keypoint adjustments)
     pose_hm = torch.cat([pose_hm[:, :1, ...], pose_hm[:, 5:, ...]], dim=1)
     ```
   - This removes COCO indices `1, 2, 3, 4` (left/right eyes and left/right ears), leaving **13 keypoints**:
     - Index `0`: Nose (COCO `0`)
     - Index `1`: Left Shoulder (COCO `5`)
     - Index `2`: Right Shoulder (COCO `6`)
     - Index `3`: Left Elbow (COCO `7`)
     - Index `4`: Right Elbow (COCO `8`)
     - Index `5`: Left Wrist (COCO `9`)
     - Index `6`: Right Wrist (COCO `10`)
     - Index `7`: Left Hip (COCO `11`)
     - Index `8`: Right Hip (COCO `12`)
     - Index `9`: Left Knee (COCO `13`)
     - Index `10`: Right Knee (COCO `14`)
     - Index `11`: Left Ankle (COCO `15`)
     - Index `12`: Right Ankle (COCO `16`)
2. **Stage 2 — Appending 14th Node (Center-Shoulder / Neck) (`13 -> 14`):**
   - `[SOURCE: ActionsEstLoader.py, TSSTG.predict]`
     ```python
     pts = np.concatenate((pts, np.expand_dims((pts[:, 1, :] + pts[:, 2, :]) / 2, 1)), axis=1)
     ```
   - Computes the midpoint of Index `1` (Left Shoulder) and Index `2` (Right Shoulder) across all `t` frames and `(x, y, score)` channels, appending it as **Index `13` (Center-Shoulder / Neck)**.
3. **Stage 3 — Graph Layout `coco_cut` (`V = 14`) & Spatial Partition (`get_adjacency`):**
   - `[SOURCE: Actionsrecognition/Utils.py, Graph.get_edge & Graph.get_adjacency]`
     ```python
     if layout == 'coco_cut':
         self.num_node = 14
         self_link = [(i, i) for i in range(self.num_node)]
         neighbor_link = [(6, 4), (4, 2), (2, 13), (13, 1), (5, 3), (3, 1),
                          (12, 10), (10, 8), (8, 2), (11, 9), (9, 7), (7, 1),
                          (13, 0)]
         self.edge = self_link + neighbor_link
         self.center = 13
     ```
   - In `get_adjacency(strategy='spatial')`:
     ```python
     normalize_adjacency = normalize_digraph(adjacency)
     # ...
     elif strategy == 'spatial':
         A = []
         for hop in valid_hop:
             a_root = np.zeros((self.num_node, self.num_node))
             a_close = np.zeros((self.num_node, self.num_node))
             a_further = np.zeros((self.num_node, self.num_node))
             for i in range(self.num_node):
                 for j in range(self.num_node):
                     if self.hop_dis[j, i] == hop:
                         if self.hop_dis[j, self.center] == self.hop_dis[i, self.center]:
                             a_root[j, i] = normalize_adjacency[j, i]
                         elif self.hop_dis[j, self.center] > self.hop_dis[i, self.center]:
                             a_close[j, i] = normalize_adjacency[j, i]
                         else:
                             a_further[j, i] = normalize_adjacency[j, i]
             if hop == 0:
                 A.append(a_root)
             else:
                 A.append(a_root + a_close)
                 A.append(a_further)
         A = np.stack(A)
         self.A = A
     ```

## Coordinate Normalization & Input Tensor Shapes
- `[SOURCE: ActionsEstLoader.py, TSSTG.predict; pose_utils.py, normalize_points_with_size, scale_pose]`
  Given raw track keypoints `pts` of shape `(T, 13, 3)` where `T = 30` and channels are `(x_pixel, y_pixel, score)`:
  1. **Resolution Normalization to `[0, 1]`:**
     `pts[:, :, :2] = normalize_points_with_size(pts[:, :, :2], image_size[0], image_size[1])`
  2. **Per-Frame Bounding-Box Min-Max Scaling to `[-1, 1]`:**
     `pts[:, :, :2] = scale_pose(pts[:, :, :2])`
     In `pose_utils.py`:
     ```python
     xy_min = np.nanmin(xy, axis=1)
     xy_max = np.nanmax(xy, axis=1)
     for i in range(xy.shape[0]):
         xy[i] = ((xy[i] - xy_min[i]) / (xy_max[i] - xy_min[i])) * 2 - 1
     ```
  3. **14th Node Concatenation:** `pts` becomes shape `(T, 14, 3)` = `(30, 14, 3)`.
  4. **Permute & Batch Expansion (Position Stream `pts`):**
     ```python
     pts = torch.tensor(pts, dtype=torch.float32)
     pts = pts.permute(2, 0, 1)[None, :]
     ```
     - **Position stream tensor shape:** `(N, C, T, V) = (1, 3, 30, 14)` where `C = 3` (`x_scaled`, `y_scaled`, `score`), `T = 30`, `V = 14`.
  5. **Temporal Difference (Motion Stream `mot`):**
     ```python
     mot = pts[:, :2, 1:, :] - pts[:, :2, :-1, :]
     ```
     - **Motion stream tensor shape:** `(N, C, T-1, V) = (1, 2, 29, 14)` where `C = 2` (`dx`, `dy`), `T-1 = 29`, `V = 14`.

## Architecture of `TwoStreamSpatialTemporalGraph` (`tsstg-model.pth`)
- `[SOURCE: Actionsrecognition/Models.py, GraphConvolution, st_gcn, StreamSpatialTemporalGraph, TwoStreamSpatialTemporalGraph]`
  - **`StreamSpatialTemporalGraph`:**
    - Input `data_bn = nn.BatchNorm1d(in_channels * A.size(1))` where `A` has shape `(3, 14, 14)` (`A.size(0) = 3` for `strategy='spatial'` and `A.size(1) = 14` nodes, so `3 * 14 = 42` channels for `pts_stream` and `2 * 14 = 28` channels for `mot_stream`).
    - 10 stacked `st_gcn` blocks with temporal kernel size `9` and spatial kernel size `A.size(0) = 3`:
      - Block 1: `in_channels -> 64`, `stride=1`, `residual=False`
      - Blocks 2, 3, 4: `64 -> 64`, `stride=1`, `residual=True`
      - Block 5: `64 -> 128`, `stride=2`, `residual=True`
      - Blocks 6, 7: `128 -> 128`, `stride=1`, `residual=True`
      - Block 8: `128 -> 256`, `stride=2`, `residual=True`
      - Blocks 9, 10: `256 -> 256`, `stride=1`, `residual=True`
    - Learnable `edge_importance = nn.ParameterList([nn.Parameter(torch.ones(self.A.size())) for i in self.st_gcn_networks])`.
    - Global average pooling `F.avg_pool2d(x, x.size()[2:])` outputting `(N, 256)` per stream.
  - **`TwoStreamSpatialTemporalGraph`:**
    - `self.pts_stream = StreamSpatialTemporalGraph(in_channels=3, graph_args=graph_args, num_class=None, edge_importance_weighting=edge_importance_weighting)`
    - `self.mot_stream = StreamSpatialTemporalGraph(in_channels=2, graph_args=graph_args, num_class=None, edge_importance_weighting=edge_importance_weighting)`
    - `self.fcn = nn.Linear(256 * 2, num_class)` (`512 -> 7`)
    - Forward pass:
      ```python
      out1 = self.pts_stream(inputs[0])
      out2 = self.mot_stream(inputs[1])
      concat = torch.cat([out1, out2], dim=-1)
      out = self.fcn(concat)
      return torch.sigmoid(out)
      ```

## Code Discrepancies / Implementation Quirks & Licensing
1. **Asymmetric `normalize_digraph` vs. Unused `normalize_undigraph`:** Just like `yysijie/st-gcn` (`S1`), `Actionsrecognition/Utils.py` defines both `normalize_digraph(A)` (`Dn[i, i] = Dl[i]**(-1)`, `AD = np.dot(A, Dn)`) and `normalize_undigraph(A)` (`Dn[i, i] = Dl[i]**(-0.5)`, `DAD = np.dot(np.dot(Dn, A), Dn)`), and `get_adjacency` calls **`normalize_digraph(adjacency)`** (asymmetric column normalization $\mathbf{A}\mathbf{D}^{-1}$), leaving `normalize_undigraph` unused. Furthermore, because `self.A` is registered as a persistent PyTorch buffer (`self.register_buffer('A', A)`), `load_state_dict(..., strict=True)` will silently overwrite `self.A` with the checkpoint's `pts_stream.A` and `mot_stream.A` unless `torch.allclose(model.pts_stream.A, ckpt['pts_stream.A'])` is verified **before** `load_state_dict`.
2. **Per-Frame Bounding-Box Scaling (`scale_pose`) Destroys Aspect Ratio:** Because `scale_pose(xy)` normalizes $x$ and $y$ independently using each frame's `nanmin` and `nanmax` (`((xy[i] - xy_min[i]) / (xy_max[i] - xy_min[i])) * 2 - 1`), a standing person and a lying person are both stretched to $[-1, 1] \times [-1, 1]$ in `pts`, making `pts` depend on relative joint configuration within the bounding box while `mot` (computed *after* `scale_pose` in `ActionsEstLoader.py`) measures differences of bounding-box-normalized coordinates rather than raw image-space velocities.
