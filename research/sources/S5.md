## Problem Addressed & Dataset Curation
- `[SOURCE: README.md & arXiv:2502.19048 Abstract]` The original UP-Fall dataset suffers from background clutter, mislabeled non-impact sliding events, and noisy 2D pose extractions.
- Extracts **33 3D skeletal joints** ($x, y, z$ and visibility score) per frame using **MediaPipe BlazePose** and provides binary impact labels (`LABEL = 1` for fall impact, `0` for non-impact/ADL) stored in CSV files (`C{camera}S{subject}A{activity}T{trial}.csv`) hosted on Zenodo (`10.5281/zenodo.12773012`) `[SOURCE: Tresor-Koffi/3D_skeletons-UP-Fall-Dataset/README.md]`.
