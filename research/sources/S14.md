## Problem Addressed
Real-time vision-based fall detection from single-camera video sequences that remains robust across different indoor environments and camera locations `[SOURCE: Abstract, 10.1117/1.JEI.22.4.041106]`.

## Dataset Specification (The Le2i / ImViA Benchmark)
- **Total Video Sequences**: **191 video sequences** (with a widely distributed subset of **130 annotated benchmark sequences**) `[SOURCE: Dataset description, 10.1117/1.JEI.22.4.041106]`.
- **Frame Rate**: **25 frames per second (fps)** (resolution $320 \times 240$) `[SOURCE: Dataset description, 10.1117/1.JEI.22.4.041106]`.
- **Four Indoor Environments**:
  1. **Home**
  2. **Coffee room**
  3. **Office**
  4. **Lecture room** (also referred to in some secondary citations as Reading room) `[SOURCE: Dataset description, 10.1117/1.JEI.22.4.041106]`.
- **Challenging Factors**: Variable illumination, shadows, reflections, occlusions by furniture (tables, chairs, sofa), different actors, and varied clothing, plus ADLs (walking, sitting, lying on sofa, bending, crouching) `[SOURCE: Dataset description, 10.1117/1.JEI.22.4.041106]`.

## Method & Evaluation Protocols
1. **STHF Descriptor (Spatio-Temporal Human Feature)**:
   - Combines bounding box height and width, trajectory, body orientation, projection histograms, and image moments of **orders 0, 1, and 2** `[SOURCE: Abstract / Methodology, 10.1117/1.JEI.22.4.041106]`.
   - Evaluates transformations including Fourier, wavelet, and **first ($\Delta$) and second ($\Delta^2$) temporal derivatives**, finding that combining **original low-level features with their first-order temporal derivatives** offers the best accuracy-speed trade-off `[SOURCE: Abstract, 10.1117/1.JEI.22.4.041106]`.
2. **Evaluation Protocols**:
   - **Protocol 1 ($P_1$)**: Standard cross-validation / split evaluation across the dataset sequences `[SOURCE: Methodology summary, 10.1117/1.JEI.22.4.041106]`.
   - **Protocol 2 ($P_2$ — Cross-Location Adaptation Protocol)**: Evaluates robustness to **location/environment changes** (e.g., training on Home/Coffee room and testing on Office) and introduces a realistic protocol that updates the training set using only **normal (non-fall) activities recorded in the new target location**, improving cross-environment generalization without requiring falls to be staged in every new room `[SOURCE: Abstract, 10.1117/1.JEI.22.4.041106]`.
