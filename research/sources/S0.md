## 2. Problem Addressed & Scope
- Implements a real-time or offline video pose-based candidate detector for `fall` and `lying` events using Ultralytics `yolo26x-pose.pt` + built-in `ByteTrack` (`bytetrack.yaml` or `botsort.yaml`), with thresholds tuned on the Le2i dev split (Lines 3–7).
- Explicitly states: `"Alerts are CANDIDATES for operator review. This script never confirms a fall by itself."` (Line 8).

## 3. Method & Exact Code Formulas
- **Default Thresholds (`THRESHOLDS`, Lines 28–34)**:
  - `sampling`: `conf_kp=0.3`, `smooth_s=0.4`
  - `fall`: `drop=0.10`, `vdown=0.15`, `window_s=2.0`, `post_s=3.0`, `low_hip=0.45`, `angle=55`, `aspect=0.9`, `head_low=0.0`, `stable_s=0.6`, `max_motion=1.5`, `hold_s=1.0`
  - `lying`: `angle_in=35`, `angle_out=20`, `aspect_in=0.5`, `aspect_out=0.3`, `T_lying=2.0`, `hold_s=1.0`, `max_motion=1.0`
  - `events`: `cooldown_s=5.0`
- **Feature Extraction (`compute_features`, Lines 53–74)**:
  - Filters keypoints by confidence `kp[..., 2] >= conf_kp` (`0.3`); low-confidence keypoints set to `np.nan` (Line 57).
  - Computes shoulder midpoint `sh = np.nanmean(xy[:, [5, 6]], axis=1)`, hip midpoint `hp = np.nanmean(xy[:, [11, 12]], axis=1)`, and head midpoint `head = np.nanmean(xy[:, [0, 1, 2]], axis=1)` (Line 58).
  - Computes torso angle relative to vertical: `angle = np.degrees(np.arctan2(np.abs(d[:, 0]), np.abs(d[:, 1])))` where `d = sh - hp` (`0°` = vertical, `90°` = horizontal) (Lines 59–60).
  - Computes reference height `ref_h` as the 90th percentile of bounding box height `h = np.maximum(box[:, 3] - box[:, 1], 1.0)` over a rolling `10000ms` (10s) window (Lines 61–62).
  - Computes relative hip height above bounding box bottom: `hip_rel = (box[:, 3] - hp[:, 1]) / ref_h` and relative head height `head_rel = (box[:, 3] - head[:, 1]) / ref_h` (Lines 63, 66).
  - Smooths `angle`, `aspect` (`w/h`), `hip_rel`, `head_rel` using rolling mean over `smooth_s = 0.4s` (Lines 64–66).
  - Computes downward hip velocity `v[1:] = -np.diff(f['hip_rel']) / dt` (Line 68).
  - Computes keypoint motion speed `mo[1:] = np.nanmean(np.linalg.norm(xy[1:] - xy[:-1], axis=2), axis=1) / ref_h[1:] / dt`, sets tracking gaps `np.diff(t) > cfg['lying']['hold_s']` to `np.nan`, and smooths `motion` over `1.0s` (Lines 69–73).
- **Hysteresis & State Holding (`hold_runs`, `merge_runs`, `lying_cond`, Lines 76–108)**:
  - `hold_runs` maintains a run across `NaN` values up to `hold_s` (`1.0s`), terminating the run if `c == 0` or if time since `prev` or `last_true` exceeds `hold_s`.
  - `lying_cond` uses hysteresis: `ein` (`1.0`) when `(ang > 35) & (asp > 0.5)` (or box-only fallback `asp > 0.5 * 1.3` when `ang` is `NaN`), `eout` (`0.0`) when `(ang < 20) | (asp < 0.3)`, and `NaN` in between (Lines 104–108).
- **Detectors (`detect_lying` Lines 110–117, `detect_falls` Lines 119–141)**:
  - `detect_lying`: Emits candidate (`priority='normal'`) when merged run duration `e - s >= T_lying` (`2.0s`) and mean motion `_mean_in(f['motion'], t, s, e) <= max_motion` (`1.0`).
  - `detect_falls`: Triggers `hit` when rolling `2.0s` drop in `hip_rel > 0.10` AND rolling `2.0s` max `vdown > 0.15`. Then checks post-impact window `[t[i], t[i] + 3.0s]` for `low & horiz` (`hip_rel < 0.45` AND (`angle > 55` OR `aspect > 0.9` OR `head_rel < 0.0`)) held for `stable_s = 0.6s` with mean motion `<= 1.5`. Emits candidate (`priority='high'`).
- **Streaming Buffer (`FallMonitor`, Lines 145–170)**:
  - Sliding window `buffer_s = 30.0s`, evaluates every `eval_every_s = 0.5s` per track with at least 5 samples, deduplicating alerts via `realert_s = 60.0s` and `cooldown_s = 5.0s`.

## 4. Stated & Structural Limitations Identified in Code
1. **No Prolonged Immobility Detector**: Does not implement candidate immobility detection for non-lying postures or general stationary states (Acceptance Criterion #3).
2. **Lower-Body Keypoints (`13, 14` knees, `15, 16` ankles) Unused**: `compute_features` only reads keypoints `[0,1,2]` (head), `[5,6]` (shoulders), and `[11,12]` (hips) (Line 58). It cannot compute knee angles, hip-knee-ankle articulation, or hip-to-ankle vertical support to separate deep bending/kneeling/sitting from falls.
3. **`hip_rel` Referenced to Self-Bounding-Box Bottom (`box[:, 3]`)**: `hip_rel = (box[:, 3] - hp[:, 1]) / ref_h` measures distance from the bottom of the current frame's bounding box rather than lower-limb length or scene floor level.
4. **10-Second Rolling `ref_h` Decay**: Because `ref_h` uses a `10000ms` rolling window (`Line 62`), after a person sits, crouches, or lies down for >10 seconds, `ref_h` shrinks to the compressed bounding box height, inflating relative motion and distorting `hip_rel`.
